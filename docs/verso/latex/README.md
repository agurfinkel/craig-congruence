# Third-party LaTeX class

`llncs/llncs.cls` is Springer's unmodified LNCS class, version 2.26
(2025-02-25), downloaded from
<https://mirrors.ctan.org/macros/latex/contrib/llncs.zip>.

Copyright 1996–2025 Springer. Distributed under CC BY 4.0 or later;
see the upstream `llncs/README.md` and
<https://creativecommons.org/licenses/by/4.0/>.

Project-specific presentation changes live in `../lncs.tex` and the adapter
in `scripts/build_pdf.py`, not in the class. The document uses the official
paper layout, but remains an audit manual rather than a submission prepared
to satisfy a venue's editorial requirements.
